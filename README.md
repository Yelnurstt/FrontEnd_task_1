## Как запустить проект (Setup Instructions)

Проект использует `json-server` для симуляции REST API. Для корректной работы требуются 2 терминала.

**1. Установка зависимостей:**
`npm install`

**2. Запуск локальной базы данных (JSON Server):**
В первом терминале выполните команду:
`npx json-server --watch db.json --port 5000`

**3. Запуск клиентского приложения (Vite):**
Во втором терминале выполните:
`npm run dev`
